# 💻 Laptop Price Prediction App

This project is a Machine Learning web application built with **Streamlit** that predicts the price of a laptop based on its hardware specifications. The goal of this project is to demonstrate the complete workflow of building, training, tuning, and deploying a machine learning regression model.

## 🚀 Live Demo

https://laptop-price-predictor-18.streamlit.app/

## ✨ Features

- Predicts laptop prices using a trained **Lasso Regression** model.
- Simple and interactive Streamlit interface.
- Instant price prediction based on user input.
- Easy-to-use dropdowns, sliders, and input fields.
- Includes feature engineering and preprocessing before prediction.

## 📋 Input Parameters

The model uses the following laptop specifications:

- Company
- Laptop Type
- Screen Size (Inches)
- RAM
- Weight
- Operating System
- SSD Storage
- HDD Storage
- Flash Storage
- Hybrid Storage
- Touch Screen
- IPS Display
- PPI (Pixels Per Inch)
- CPU Brand
- CPU Family
- CPU Clock Speed
- GPU Brand

## ⚙️ How to Run the Project

Clone the repository:

```bash
git clone https://github.com/krishnatyagijee-max/Laptop-Price-Prediction.git
```

Move into the project folder:

```bash
cd Laptop-Price-Prediction
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```

## 🧠 Machine Learning Model

**Algorithms Implemented**

- Linear Regression
- Ridge Regression
- Lasso Regression
- K-Nearest Neighbors Regressor (KNN)
- Support Vector Regressor (SVR)
- Decision Tree Regressor

**Hyperparameter Tuning:** GridSearchCV

**Final Model:** Lasso Regression

**Evaluation Metrics:**

- R² Score
- Adjusted R² Score
- 5-Fold Cross Validation
